# ruggie
A game engine for hombrew 3DS games

This is the high level Game Engine built on top of [ruggie-lib](https://github.com/3ds-engine/ruggie-lib)'s abstractions. Games are made in ruggie using the [lua scripting language](https://www.lua.org/)

## Roadmap
- Lua engine API
- Lua compilation and runtime execution
- Physics engine
    - 2D physics engine
    - 3D physics engine
- Media file to romfs converter
- Entity-Component style architecture
